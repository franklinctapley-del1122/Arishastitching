# Arisha Stitching

A responsive React + Vite landing page for a ladies stitching studio, using a pink-and-white visual identity and WhatsApp-first enquiries.

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
npm run preview
```

## WhatsApp orders

The order buttons open WhatsApp for **03081042020**. The site uses the international-format number `923081042020` in the wa.me link.

## Deploy

This project can be deployed to Vercel, Netlify, or GitHub Pages with a suitable Vite setup. For Vercel/Netlify, use `npm run build` as the build command and `dist` as the output directory.

## Before launch

- Replace the CSS-made fashion illustrations with real studio photos when available.
- Confirm current order timings, measurement method, delivery/pickup options and pricing before publishing those details.
- Add official social profile URLs if the studio uses them.
